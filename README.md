# MiniFan

Repo for the Holofan Mini at Eagletech.

The Holofan small 11.8in can take mp4s, .movs, etc. converted to .Bin files with 320x320 resolution. We use the dell pro max 16 to read the fans micro sd card found above the chip on the middle of the fan. We transfer files onto that laptop via thumb drives then copy the data onto that sd card. We then re insert the sd card into the fan.



We found the holofan software @ https://www.dropbox.com/scl/fi/q2ahu2dja8ohkj7zbgtwr/HOLOFAN-Spindisplay.zip?rlkey=e86n3s8oifslf3767y90ejtqi\&e=1\&dl=0.



The software converts ftlv which works for the bigger fan but not the smaller one. We've identified two file types needed.
